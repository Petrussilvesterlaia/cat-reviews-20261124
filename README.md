## The entry

> One star. He bought me a $400 cat tree, then looked betrayed when I slept in the box it came in. I stand by my choice.

One funny single-line one-star review, written by a house cat about the human it lives with — 118 characters, deadpan to the end.

## How it works

`main.py` writes that one line to `/output/entry.txt`, then reads the file back and checks it against the competition gate: 1–200 characters, a single line, no leading or trailing white space, no trailing newline.

```sh
python3 main.py
```
